This project is an end-to-end Natural Language Processing (NLP) web application that automatically condenses long-form documents into concise, accurate summaries.
Built using Hugging Face Transformers and PyTorch, the model leverages state-of-the-art deep learning architectures to understand context and generate human-like abstractions.
The inference pipeline is deployed through a clean, interactive Streamlit frontend, allowing non-technical users to easily test the model's capabilities.
All model checkpoints, tokenizers, and weights are managed and hosted via the Hugging Face Hub.
